# 🍎 사과게임
숫자 사과를 이어 합이 10이 되도록 만드는 1분 퍼즐 게임입니다.

## 게임 소개
8×8 보드에 1부터 9까지의 숫자 사과가 무작위로 놓입니다.
게임을 시작하고 상하좌우로 인접한 사과를 드래그해 합계 10을 만들면 획득합니다.
성공하면 선택한 사과 수만큼 점수를 얻고, 해당 칸에는 새 숫자가 채워집니다.
합계가 10을 넘으면 그 선택은 무효입니다.
제한 시간은 60초이며, 현재 점수와 최고 점수를 확인할 수 있습니다. 최고 점수는 같은 브라우저에 저장됩니다.

## 어떻게 만들었나요
Copilot과 함께 게임 규칙과 화면 구성을 정리한 뒤,
별도 라이브러리 없이 HTML, CSS, Vanilla JavaScript로 구현했습니다.
- `index.html`: 게임 화면과 점수·타이머 구조
- `style.css`: 반응형 화면과 사과 모양 보드 스타일
- `script.js`: 숫자 생성, 드래그 판정, 점수, 타이머, 최고 점수 저장

## 실행 방법
`index.html`을 브라우저에서 열면 바로 플레이할 수 있습니다. 별도의 설치나 빌드 과정은 필요하지 않습니다.
GitHub Pages에 배포할 경우 저장소 설정에서 `gh-pages` 브랜치의 루트 폴더를 배포 대상으로 선택하세요. 배포가 완료되면 이 항목에 Pages 주소를 추가할 수 있습니다.

## 커스터마이징한 부분
- 제한 시간을 예시의 2분 대신 1분으로 설정했습니다.
- 대각선 연결을 제외하고 상하좌우 인접한 사과만 선택할 수 있게 했습니다.
- 칸을 사과 모양으로 꾸미고, 성공 시 선택한 사과 수만큼 점수를 주도록 했습니다.
- 최고 점수를 브라우저에 저장하고 좁은 화면에서도 보드를 사용할 수 있게 했습니다.
자세한 실습 절차는 [guide.md](./guide.md)를 참고하세요.
